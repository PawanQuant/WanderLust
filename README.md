# WanderLust - Full Stack Airbnb Clone

WanderLust is a comprehensive vacation rental platform built using **Node.js, Express, React, and MongoDB**. It allows users to explore unique stays, manage listings, and experience a seamless booking flow.

## 🔗 Live Demo
Check out the live website here: [WanderLust Live Website](https://tumhari-render-link-yahan-daalo.onrender.com)

---

### Key Features
- **Listing Management:** Full CRUD operations for vacation rentals.
- **Responsive Design:** Built with **Bootstrap** for a mobile-first experience.
- **Data Integrity:** Robust Schema validation using **Mongoose**.
- **User Experience:** Seamless navigation and dynamic image handling.

### Tech Stack
- **Frontend:** React.js, HTML5, CSS3, Bootstrap 5.
- **Backend:** Node.js, Express.js.
- **Database:** MongoDB (with Mongoose ODM).
- **Tools:** Git, GitHub, Postman.
